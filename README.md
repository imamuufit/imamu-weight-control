# imamu. Weight Log

LINE公式アカウントのリッチメニューから開く想定の、スマホ優先の体重管理PWAです。

## 使い方

1. GitHub Pagesで、このフォルダのルートを公開します。
2. 公開URLをLINE公式アカウントのリッチメニューに設定します。
3. ユーザーは初期設定を入力し、毎日の体重と体調メモを記録します。

## 主な機能

- 目標体重、目標期限、活動量の初期設定
- 毎日の体重と体調メモの保存
- 7日平均と先週平均比の自動計算
- 体重グラフ、7日平均、目標ライン表示
- 推定消費カロリー、目的別摂取カロリー、PFC目安
- 週間チェック
- 進捗に応じた簡易アドバイス
- LINE報告用コピー
- CSVエクスポート
- データ削除
- PWA manifestとservice worker

## 保存先

記録データは利用者のブラウザ内のlocalStorageに保存されます。サーバー送信は行いません。

## 注意

このアプリは体重管理の記録補助であり、医療診断や治療を目的としたものではありません。妊娠中、治療中、摂食障害の既往がある方、医師から食事制限を受けている方は、医師や専門家に相談してください。
